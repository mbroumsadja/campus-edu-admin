# campus-edu — Administration

Interface web de la plateforme universitaire.  
Connectée à l'API `campus-edu-api`.

Elle est reserver au administrateur pour l'enregistrement et la publication des documents.

---

## Stack technique

| Technologie       | Rôle                          |
|-------------------|-------------------------------|
| Next.js 14        | Framework React (App Router)  |
| TypeScript        | Typage statique               |
| Tailwind CSS      | Styles utilitaires            |
| Axios             | Client HTTP + intercepteurs   |
| js-cookie         | Gestion des tokens JWT        |
| lucide-react      | Icônes                        |
| Sora + IBM Plex   | Typographie                   |
